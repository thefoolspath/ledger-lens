# Research Sources

Last reviewed: 2026-08-11.

Use official documentation, standards, upstream release notes, provider pricing/terms, and exchange/regulator material. Record URL, title, publisher, relevant version/date, access date, and the claim supported.

Do not copy full external pages into the repository. Store a local source file only when redistribution permits it and the evidence cannot be cited reliably by URL. Do not commit authenticated provider responses, account pages, real slips, or copyrighted market datasets.

Time-sensitive sources must be rechecked at implementation and release gates. Provider pricing and entitlements are observations, not permanent promises.
