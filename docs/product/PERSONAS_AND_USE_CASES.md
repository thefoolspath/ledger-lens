# Personas and Use Cases

## Primary persona

A personal investor in Thailand who holds US stocks or ETFs through Dime, measures the portfolio primarily in USD, and also needs to understand the THB outcome.

## Core use cases

- Record or correct an investment event without rewriting history.
- Compare FIFO lots and average cost for the same holding.
- Explain whether a THB gain came from the security or USD/THB movement.
- Retrieve historical FX for a trade, retain its source, and override it with an auditable manual value.
- Fetch a quote or FX rate only when the application is open and the user requests it.
- Review a Dime slip beside extracted fields before posting.
- Research a held, watched, or searched security and preserve source links and dates.
- Restore a consistent database-and-document backup after machine loss.

## Secondary persona

An open-source contributor who works only with synthetic fixtures and can follow a decision-complete vertical plan without seeing private portfolio data.
